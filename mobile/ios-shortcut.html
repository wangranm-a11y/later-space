任何地方看到内容，
Later Space 先接住。

有两种手机入口：快捷指令无需安装 App；Share Extension 支持链接、文字和相册图片，并能离线排队。

快捷指令

零成本、两分钟搭好，适合先开始使用。

iOS App

分享体验更完整，失败时保存在手机等待重试。

快捷指令设置

  1. 新建快捷指令，打开“在共享表单中显示”，接收“网址”和“文本”。
  2. 添加“如果”：如果快捷指令输入是 URL，把它设为变量 url；否则设为变量 text。
  3. 添加“获取 URL 内容”，地址填写 http://你的电脑IP:5177/api/inbox，方法选择 POST。
  4. 请求正文选择 JSON，加入 url、text、source 三个字段；source 固定为 ios-shortcut。
  5. 若设置了令牌，在请求头加入 X-Later-Space-Token。
  6. 最后添加“显示通知”：文案写“Later Space 已接住”。
{
  "kind": "链接存在时填 link，否则填 text",
  "url": "url 变量",
  "text": "text 变量",
  "source": "ios-shortcut"
}

本地服务准备

  1. 让 iPhone 和 Mac 连接同一个 Wi-Fi。
  2. 运行：LATER_SPACE_HOST=0.0.0.0 LATER_SPACE_CAPTURE_TOKEN="一段随机密码" python3 server.py。
  3. 在 Mac 网络设置中查看局域网 IP，例如 192.168.1.8。

本地模式下，Mac 休眠或不在同一网络时，快捷指令无法发送；iOS App 会先把内容留在手机队列。真正跨网络自动同步，需要部署独立的公网收件箱 API，不能直接使用 GitHub Pages 或 Vercel 静态网址。
