# Later Space 手机端教程：从零开始

目标：先在 iPhone 分享菜单里配置好“收进 Later Space”，以后保存链接、文字和图片只需要两下。主屏幕安装是最后的可选步骤。

## 1. Safari 输入 Later Space 网址

打开 Safari，在地址栏输入 `https://wangranm-a11y.github.io/later-space/`，点键盘右下角“前往”。现在还不用打开“快捷指令”，先把 Later Space 登录好。

## 2. Later Space 登录页

点“登录”或“开始使用”。推荐点“使用 Google 账号继续”，选择自己的账号；也可以输入邮箱，去邮件里点击 Later Space 发来的登录链接，再回到 Safari。Later Space 只用邮箱确认账号，不会读取 Gmail 内容。

## 3. 同步中心生成个人收件地址

登录后打开账号菜单，进入“同步中心”。找到“手机分享入口”，点“生成专属地址”，再点“复制收件地址”。复制的是一条很长的专属地址，不是 Later Space 首页网址；它相当于你的私人投递入口，请不要发给别人。复制后先不要关闭 Safari，接下来要粘贴到快捷指令里。

## 4. 快捷指令新建页面

打开 iPhone 的“快捷指令”App，点右上角“＋”。点顶部名称，把它改成“收进 Later Space”，然后点“添加操作”。这一步是在创建一个新的分享入口，不是在安装 Later Space App。

## 5. 开启共享表单

点快捷指令详情里的设置图标或“信息”按钮，打开“在共享表单中显示”。这一步不用搜索，也不用添加动作；只需要打开开关。

### 这一步到底勾选什么？

**特别注意：接收类型不要选择“任何”。**请把接收类型改成下面这三个：

- `网址`：**必选**。从 X、Safari 或其他 App 分享网页时，Later Space 需要拿到原始链接，之后才能点“打开原链接”回到 X。
- `文本`：**必选**。有些 App 分享的是标题、说明文字或选中的文字，不是一个单独的网址；打开它才能避免这类分享没有输入。
- `图片`：**可选**。如果你想从照片 App 分享图片，就打开它；只分享 X 链接时可以不打开。

你的截图里就是正确的状态：`网址`、`文本`、`图片`为绿色开启，其他类型关闭。

### 为什么其他类型先不选？

- `任何`：范围太宽，可能把网页预览、富文本或文件容器一起传进来，容易出现乱码或快捷指令无法处理。
- `Safari 浏览器网页`、`文章`、`多信息文本`：这些通常是带格式的网页内容，不一定是 X 的原始 URL；当前目标是先稳定保存链接和普通文字。
- `媒体`：主要用于视频或音频，当前 Later Space 手机分享入口还没有按媒体文件设计。
- `文件`、`文件夹`、`PDF`：属于文件上传场景，和这条“分享网页 / 文字 / 图片”的快捷指令不是同一条路径；以后要支持文件时再单独增加。
- `地图链接`等其他类型：当前收件接口没有为它们做专门处理，先关闭可以减少误传。

这不是“越多越好”的选择，而是给快捷指令设置一个**允许接收的输入白名单**：先只接收 Later Space 能稳定识别的类型。

设置完后点“完成”或“回到编辑页面”。

你应该看到：开关已经打开，并且快捷指令编辑页面最上方出现了“快捷指令输入”。如果没有看到，说明你还在“添加操作”的搜索页面，需要先返回快捷指令编辑页，再点顶部的设置/信息图标。

## 6. 添加 URL 动作

点“添加操作”，搜索 `URL`，选择名为“URL”的动作。点进动作里的蓝色地址框，粘贴第 3 步复制的个人收件地址。不要粘贴 Later Space 首页网址，也不要手动删掉地址里的参数。

**这里的 `URL` 和上一步的接收类型 `网址` 不是同一个东西：**上一步是在说“这个快捷指令允许接收什么”；这一步是在说“请求应该发送到哪个 Later Space 收件地址”。

## 7. 添加获取 URL 内容

再次点“添加操作”，搜索并添加“获取 URL 内容”。把这个动作放在 URL 动作的下面，让它读取刚才的地址。

## 8. 设置 POST 和文件请求体

展开“获取 URL 内容”动作，逐项设置：

- 方法选择 `POST`，不要使用默认的 `GET`。
- 请求体类型选择“文件”。如果看不到“请求体”，先点“显示更多”。
- 文件输入框选择“快捷指令输入”。它代表你从 Safari、照片或其他 App 分享进来的内容。

设置完成后的顺序应该是：`URL` → `获取 URL 内容（POST / 文件 / 快捷指令输入）`。

## 9. 添加成功通知

在“获取 URL 内容”下面再添加“显示通知”动作。通知文字输入：`✓ 已加入 Later Space`。这样每次分享后，iPhone 都会明确告诉你是否已经完成。

## 10. 先测试一次分享

回到 Safari，打开任意网页，点底部分享按钮，在 App 图标区域找到“收进 Later Space”。点它后等待通知：先看到 `✓ 已加入 Later Space`，再打开 Later Space 的“未整理”收件箱，确认刚才的网页出现在第一条。

来源不限制：Safari、X、微信、备忘录、照片等都可以分享；限制的是“接收类型”，不是 App 来源。若分享菜单里没有它：在 App 图标区域向左滑，点“更多”→“编辑”，把“收进 Later Space”打开。若通知提示失败，回到快捷指令检查 URL 是否完整、方法是否为 `POST`、请求体是否为“文件”。从 X 分享时，Later Space 会优先保存 X 的原始链接；手机详情页里点击“打开原链接”即可回到 X。不要把 X 的网页预览或乱码文件当成普通文字保存。

## 11. 手机详情页删除内容

在手机 Web App 的收件箱里：

- **点击**一条内容：进入“专注查看”详情页。向下可以点“在完整画布中查看”或“删除这条内容”。
- **长按**一条内容约半秒：会弹出删除确认，不用进入详情页。确认后内容会从手机收件箱移除，也会同步到其他设备。

删除前一定会二次确认；如果误删，可以马上点提示里的“撤销”。

## 12. 更快删除：从右往左滑

在收件箱外层，把一条卡片从右往左滑：

1. 滑出红色“删除”按钮时，可以松手，再点按钮删除。
2. 继续向左滑到尽头，会直接弹出删除确认。
3. 确认后内容进入“我的 Later Space”里的“云端回收站”，其他设备也会暂时隐藏。

回收站里的内容保留 30 天，可以点“恢复”放回收件箱，也可以点“永久删除”。图片在进入回收站期间仍保留云端文件，恢复后可以继续查看。

## 13. 可选：添加到主屏幕

快捷指令测试成功后，如果你希望像打开 App 一样进入 Later Space，再回到 Later Space 网页端，打开“我的 Later Space”或“同步中心”，点击“安装到主屏幕”。按 Safari 提示完成添加即可。这个步骤只负责快速打开 Later Space，不影响前面已经配置好的分享快捷指令。

以后保存内容只需要：**分享 → 收进 Later Space → 看见绿色成功通知**。查看时可以打开原始 X 链接；不想保留时，点击进入详情删除，或直接长按收件箱卡片删除。
