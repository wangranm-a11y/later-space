# Later Space 手机端教程：从零开始

目标：在 iPhone 分享菜单里得到一个“收进 Later Space”，以后保存链接、文字和图片只需要两下。

## 1. Safari 输入 Later Space 网址

打开 Safari，在地址栏输入 `https://wangranm-a11y.github.io/later-space/`，点键盘右下角“前往”。网页里的网址卡片也提供“一键复制网址”，可以直接复制后粘贴到 Safari。现在还不用打开“快捷指令”。

## 2. Later Space 登录页

点“登录”或“开始使用”。推荐点“使用 Google 账号继续”，选择自己的账号；也可以输入邮箱，去邮件里点击 Later Space 发来的登录链接，再回到 Safari。Later Space 只用邮箱确认账号，不会读取 Gmail 内容。

## 3. 同步中心生成个人收件地址

登录后打开账号菜单，进入“同步中心”。找到“个人收件地址”，点生成，再点“复制收件地址”。这是带有个人 token 的私人投递地址，不是 Later Space 首页网址，请不要把完整地址发给别人。

## 4. 快捷指令新建页面

打开 iPhone 的“快捷指令”App，点右上角“＋”，新建快捷指令，并命名为“收进 Later Space”。在详情设置里开启“在共享表单中显示”，接收类型保留“任何”。

## 5. 添加 URL 动作

点“添加操作”，搜索 `URL`，选择“URL”动作。长按蓝色地址框，粘贴第 3 步复制的个人收件地址。

## 6. 设置 POST + 文件请求体

添加“获取 URL 内容”动作，并设置：

- 方法：`POST`
- 请求体：`文件`
- 文件：`快捷指令输入`

“快捷指令输入”就是以后从 Safari、照片或其他 App 分享进来的内容。再添加“显示通知”动作，并选择上一步的“URL 内容”；成功时会显示“✓ 已加入 Later Space”。

## 7. 分享菜单选择“收进 Later Space”

打开 Safari 的任意网页，点分享按钮，在分享菜单里选择“收进 Later Space”。如果没有看到：向左滑 App 图标 → 点“更多”→“编辑”→ 打开“收进 Later Space”。

## 8. 成功通知和“未整理”收件箱

看到“✓ 已加入 Later Space”通知后，回到 Later Space 网页，打开“未整理”。刚才分享的内容应当出现在第一条。

以后保存内容只需要：**分享 → 收进 Later Space**。
