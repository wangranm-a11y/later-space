# Later Space 插件新手引导与反馈实施计划

依据：`docs/superpowers/specs/2026-09-02-extension-onboarding-feedback-design.md`

## 阶段 1：建立扩展行为契约

1. 新增静态回归测试，约束首次安装判断、引导入口、引导状态、提示音默认值、练习清理和版本号。
2. 先运行新增测试并确认失败，证明测试覆盖的是尚未实现的行为。
3. 保留现有选区位置和 10ms 响应测试，避免视觉优化造成历史行为回退。

## 阶段 2：共享提示音与浮动图标状态

1. 新增 `feedback-sound.js`，集中处理默认开启的提示音偏好和 Web Audio 成功双音。
2. 在普通网页内容脚本、插件弹窗和新手引导页中复用该模块。
3. 为浮动图标增加完全不透明的悬浮态和约 4% 的按下态，同时保留默认的低对比半透明状态。
4. 只在 `saved` 和 `duplicate` 结果播放成功音；`queued`、`unavailable` 和浏览器音频限制保持静默。

## 阶段 3：首次安装与引导状态

1. 将 `onInstalled` 改为区分 `install` 与 `update`：仅首次安装自动打开 `welcome.html`。
2. 在 `chrome.storage.local` 保存引导版本、当前步骤、完成状态、练习会话 ID 和练习内容 ID。
3. 增加 runtime message 契约，让引导页读取、推进和完成状态，而不直接访问保存实现。
4. 已有用户升级不自动打开；主动从插件弹窗或设置页打开时允许重新查看。

## 阶段 4：B 版真实操作引导页

1. 新增 `welcome.html`、`welcome.css` 和 `welcome.js`，实现真实操作演示风格。
2. 第一步让用户真实拖选模拟文章；在最后一行右下角显示同款收藏图标并保存练习文字。
3. 第二步使用内置生成的示例图片，让用户悬停并真实保存练习图片。
4. 第三步说明工具栏收藏网页，以及“不登录也能用、登录后跨设备同步”的区别。
5. 完成页展示查看、保留和删除练习内容入口，并支持中途关闭后恢复进度。

## 阶段 5：练习收藏与可靠清理

1. 在 service worker 新增专用练习收藏消息，沿用 `saveCapture`、云端直存、网页桥接和待发送队列。
2. 给练习内容增加 `onboarding` 与 `onboardingSessionId` 标记，并记录真实返回的内容 ID。
3. 新增不受 60 秒限制的练习清理：先移除待发送队列，再删除 Supabase 或网页本地记录。
4. 部分失败时保留未清理 ID并返回可重试状态，不显示虚假的成功结果。

## 阶段 6：插件入口与设置

1. 在插件弹窗底部加入轻量“使用指南 · 设置”入口，不改变主收藏按钮尺寸和优先级。
2. 未完成引导时显示“继续新手引导”，完成后显示“使用指南”。
3. 设置页增加“收藏提示音”开关与“重新查看使用指南”入口。
4. 设置修改立即写入本地并反映到后续收藏操作。

## 阶段 7：验证、打包与浏览器更新

1. 运行 JavaScript 语法检查、manifest JSON 检查、完整 Python 测试和 `git diff --check`。
2. 使用 Ego Lite 验证首次安装、升级不弹出、中途恢复、文字/图片真实收藏、登录跳过、声音开关和练习清理。
3. 使用视觉审查检查引导页的排版、层级、间距、对比度和窄屏表现，并修复高优先级问题。
4. 提升扩展版本号，生成新 zip，校验压缩包内容。
5. 覆盖 Ego Lite 当前加载目录，重新载入并确认扩展无清单错误或运行错误。
6. 只提交本功能相关源码、测试和安装包，保留工作区其他未提交内容。

## 提交策略

- 计划文档单独提交。
- 实现按“行为与状态”“引导 UI”“入口与设置”“发布包”分组提交，若文件耦合导致无法安全拆分，则合并为一次聚焦提交。
- 每个阶段先通过对应测试，再进入下一阶段。
