# Later Space 插件新手引导与反馈设计

日期：2026-09-02

## 目标

让第一次安装 Later Space 插件的用户在几分钟内完成一次真实收藏，理解文字、图片和网页三种入口，并知道登录不是使用门槛，而是跨浏览器、跨设备同步的开关。同时提升浮动收藏图标的悬浮、按下和成功反馈质感。

## 范围

本次包括：

- 浮动图标悬浮与按下状态。
- 收藏成功提示音及开关。
- 首次安装自动打开的完整新手引导页面。
- 可恢复的引导进度。
- 真实练习内容的创建、查看和清理。
- 插件弹窗底部的“使用指南 · 设置”入口。

本次不包括：

- 改造 Later Space 网页的主界面。
- 同步提示音偏好或引导进度到云端。
- 为老用户在插件升级后强制打开引导。
- 复杂音效主题或音量调节。

## 体验原则

1. 用户通过真实操作学习，而不是阅读大段说明。
2. 不登录也能开始使用；登录只用于跨浏览器、跨设备同步。
3. 成功音代表内容已经保存成功，不能只代表用户点过按钮。
4. 引导可以关闭和跳过，不阻止插件正常使用。
5. 练习内容必须可识别、可查看、可彻底清理。

## 首次安装流程

扩展在 `chrome.runtime.onInstalled` 收到 `reason === "install"` 时打开内置 `welcome.html`。`reason === "update"` 时不自动打开，避免打扰已有用户。

引导采用已确认的“真实操作演示”方向，共四个阶段：

### 1. 收藏文字

页面展示一段模拟文章。用户真实拖选指定文字后，收藏图标约 10ms 后出现在选区最后一行右下角。用户悬浮并点击图标后，插件通过现有收藏链路保存一条带练习标记的文字内容。

保存成功或判定为重复内容后播放成功音，并展示“已加入 Later Space”。离线排队或失败时不播放成功音。

### 2. 收藏图片

页面展示一张内置示例图片。用户悬浮图片后点击收藏图标，插件通过现有图片收藏链路保存一条带练习标记的图片内容。成功后进入下一步；失败时保留当前步骤并提供重试。

### 3. 收藏网页与登录说明

页面用真实界面示意说明：点击浏览器工具栏中的 Later Space 插件，可以收藏当前网页。此步骤以认知讲解为主，不强制再创建一条练习数据。

同一页面明确说明：

- 现在就能用：未登录时内容保存在当前浏览器的 Later Space。
- 登录后同步：使用同一邮箱后，Chrome、Edge 和其他设备的内容会汇总到同一 Supabase 账户。

提供“连接 Later Space”和“暂不登录”两个入口。跳过登录不影响完成引导。

### 4. 完成与清理

完成页展示本次生成的练习内容，并提供：

- 查看练习内容。
- 保留练习内容。
- 删除全部练习内容。

删除不使用普通收藏的 60 秒撤销期限。插件保存本次练习产生的内容 ID，并通过专门的清理消息删除云端记录、网页本地记录和待发送队列中的对应项目，防止内容稍后重新出现。

## 引导状态

插件在 `chrome.storage.local` 保存独立的引导状态，包括：

- 引导版本。
- 当前步骤。
- 是否完成。
- 本次练习内容 ID。
- 是否已经选择保留练习内容。

中途关闭页面后不再次强制弹出。下次打开插件时，在不干扰主操作的位置显示“继续新手引导”。完成后该入口恢复为普通“使用指南”。以后即使引导内容升级，也只有用户主动打开时才展示新版，不自动打扰。

## 浮动图标反馈

### 默认状态

- 保留低对比、半透明背景和当前轻阴影。
- 位置继续使用选区最后一行右下角，页面上始终只有一个图标。

### 悬浮状态

- 图标与背景过渡到完全不透明。
- 阴影略微清晰。
- 向上移动 1px。
- 过渡保持短促，不产生弹跳感。

### 按下状态

- 图标缩小约 4%。
- 松开后恢复。
- 视觉按压不等同于收藏成功；最终状态仍由保存结果决定。

## 提示音

提示音默认开启，可在设置页关闭。偏好保存在 `chrome.storage.local`，不跨设备同步。

提示音规则：

- `saved`：播放。
- `duplicate`：播放，因为用户目标已经达成。
- `queued`：不播放，显示“已暂存，连接后自动加入”。
- `unavailable`：不播放，显示对应失败提示。
- 浏览器阻止音频：忽略音频错误，视觉反馈继续工作。

声音为约 120–180ms 的低音量轻短双音。为避免额外二进制资源和播放延迟，优先使用 Web Audio API 在用户点击后的有效手势上下文中生成，并在保存成功后触发已准备好的音频节点。若浏览器限制导致无法播放，不做二次弹窗。

## 插件弹窗与设置页

插件弹窗底部增加轻量文字入口：

`使用指南 · 设置`

- “使用指南”打开 `welcome.html`；若引导未完成，文案显示为“继续新手引导”。
- “设置”打开现有设置页。
- 两者使用小号灰色文字，不增加主按钮，不削弱“加入当前网页”的视觉优先级。

设置页新增：

- “收藏提示音”开关，默认开启。
- “重新查看使用指南”入口。

## 组件边界

### `welcome.html` / `welcome.js` / `welcome.css`

负责引导页面展示、步骤推进、练习操作和完成页。只通过明确的 runtime message 与 service worker 通信，不直接复制云端或本地保存逻辑。

### `service-worker.js`

继续作为收藏结果的唯一协调者，并新增：

- 首次安装打开引导页。
- 引导状态读取与更新。
- 练习收藏标记和练习内容清理。
- 提示音设置读取接口。

### `page-feedback.js`

负责普通网页中的浮动图标视觉状态和成功音触发。引导页可以复用同一套视觉参数，但练习事件仍交由 service worker 保存。

### `popup.*` 与 `options.*`

只负责入口和设置，不承载完整引导内容。

## 数据标记与清理

练习收藏沿用普通内容结构，但增加稳定的产品标记，例如 `onboarding: true` 和 `onboardingSessionId`。该标记写入 Later Space 内容数据，不包含用户行为分析信息。

清理流程：

1. 从引导状态读取本次练习 ID。
2. 从插件待发送队列移除相同 ID。
3. 已登录时将 Supabase 对应记录标记删除。
4. 未登录或网页本地模式时，通过现有页面桥接删除对应记录。
5. 清空本次引导状态中的练习 ID。

部分删除失败时保留未清理 ID，并显示“还有练习内容未删除，重试”。不能在失败时假装清理完成。

## 异常处理

- 引导页面被关闭：保存当前步骤，下次从插件入口继续。
- 当前网页禁止内容脚本：保留右键菜单和插件弹窗入口，不将其视为引导失败。
- 未登录且 Later Space 页面暂时不可用：练习内容进入现有待发送队列，页面明确显示暂存状态，不播放成功音。
- 登录过程中离开引导：登录完成后仍可回到原步骤；插件自动导入 Supabase 会话。
- 图片无法读取：显示可重试提示，不自动跳过。
- 重复练习内容：视为收藏成功，但记录实际返回的内容 ID，避免删除错误内容。

## 测试与验收

### 自动测试

- 只有首次安装会自动打开引导，升级不会打开。
- 提示音默认开启，设置可关闭并持久化。
- 成功和重复状态触发声音；排队和失败状态不触发。
- 引导步骤和练习 ID 可以保存、恢复。
- 清理同时覆盖待发送队列、云端记录和本地页面记录。
- 悬浮状态完全不透明，按下状态存在缩放反馈。
- 弹窗包含“使用指南 · 设置”，且主收藏按钮结构不改变。

### Ego Lite 真实验收

- 全新安装后自动打开引导页一次。
- 完成文字和图片两次真实练习收藏。
- 登录与跳过登录两条路径均可完成引导。
- 中途关闭后可从插件弹窗继续。
- 设置页可以关闭提示音，关闭后收藏无声音但视觉反馈正常。
- 完成页可以定位并删除全部练习内容，刷新 Later Space 后不会重新出现。
- 旧用户从上一版本升级后不会自动弹出引导。
