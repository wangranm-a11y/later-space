第 5 步 · 允许分享

不用搜索，
先开共享表单

点快捷指令顶部的设置/信息图标，打开“在共享表单中显示”。这一步不用搜索，也不用添加动作。

特别注意：不要选“任何”
接收类型请改成：网址、文本；如果还要从照片 App 分享图片，再加上图片。最终看到：网址 · 文本 · 图片（可选）。
把“如果没有输入：继续”改掉。
回到编辑页顶部的“从共享表单接收…”动作，点“如果没有输入”后面的“继续”，改成“请求输入”，输入类型选“文本”。X 没有传来链接时，手机就会让你粘贴链接，不会发送空请求；正常分享不会多一步。
为什么是这三个？
网址负责保存 X 的原始链接；文本负责接收标题、说明和选中的文字；图片负责从照片 App 分享图片。它们是 Later Space 当前最稳定处理的三种输入。
为什么不选其他的？
任何范围太宽，可能把网页预览或富文本当成文件传入；“Safari 浏览器网页”“文章”“多信息文本”可能带入网页格式；“媒体”“文件”“文件夹”“PDF”则是另一套文件上传场景，暂时容易导致乱码或无法处理。
怎么确认成功？
点“完成”回到编辑页面，看到“快捷指令输入”出现在最上方，并且“如果没有输入”显示“请求输入”。
如果你还在“添加操作”的搜索页，先返回编辑页，再点顶部设置图标。

第 6 步 · 添加地址

URL
粘贴收件地址

回到编辑页面，点“添加操作”，搜索并选择“URL”。点蓝色地址框，粘贴第 3 步复制的个人收件地址。

和上一步有什么不同？
上一步的“网址”是允许接收的内容类型；这里的“URL”动作是告诉快捷指令把请求发送到哪个 Later Space 收件地址。

第 8 步 · 显示真实结果

通知要显示
服务器的回复

在“获取 URL 内容”下面添加“显示通知”。点通知文字，删掉固定的“✓ 已加入 Later Space”，再点“选择变量”，选择上一条“获取 URL 内容”的输出。看到蓝色变量才算设置好。

不要自己写死成功文字。
之前服务器收到空请求、返回了 400，固定通知仍显示“✓”，造成了假成功。现在保存成功才会显示服务器返回的“✓ 已加入 Later Space”；失败时会看到错误提示，或快捷指令停在报错处。

第 9 步 · 测试成功

从 App 的分享菜单
保存原始链接

在 X 里打开一条帖子，点 X 的分享按钮，选择“收进 Later Space”。先用文字或网址测试，确认可以收件后再测试图片。

真正成功要同时满足：
通知显示服务器回复“✓ 已加入 Later Space”，并且手机收件箱里出现新链接；点“打开原链接”能回到 X 原文。
如果仍然失败：
在“获取 URL 内容”前临时添加“快速查看”，查看快捷指令输入。如果什么也没有，说明分享内容没传进来；检查第 5 步的接收类型，以及第 7 步“文件”是否选了快捷指令输入。检查完可删除“快速查看”。
如果分享菜单里没有它：向左滑 App 图标 → “更多”→“编辑”→打开“收进 Later Space”。

最后一步：可选添加到主屏幕

快捷指令测试成功后，如果你希望像打开 App 一样进入 Later Space，再回到“我的 Later Space”或“同步中心”，点击“安装到主屏幕”。这个步骤只负责快速打开 Later Space，不影响已经配置好的分享快捷指令。
