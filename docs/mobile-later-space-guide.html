第 3 幕 · 拿到钥匙

同步中心生成
个人收件地址

登录后打开账号菜单，进入“同步中心”。找到“个人收件地址”，点生成，再点复制。

你要复制的是：同步中心生成的长地址，里面通常带有 token=…。它不是 Later Space 首页网址。
这个地址相当于私人投递口，请不要截图发给别人。

第 4 幕 · 搭一个小机关

快捷指令
新建页面

回到 iPhone 主屏幕，打开“快捷指令”App。点右上角“＋”，新建一条快捷指令，并把名称改成“收进 Later Space”。

再打开详情设置：开启“在共享表单中显示”，接收类型保留“任何”。这样它才会出现在其他 App 的分享菜单里。

第 5 幕 · 放进地址

添加 URL 动作

点“添加操作”，搜索 URL，选择名字就叫“URL”的动作。然后在蓝色地址框里长按，粘贴第 3 幕复制的个人收件地址。

检查一下：地址很长是正常的；只要开头是 https://，而且末尾包含个人 token，就可以继续。

第 6 幕 · 接上发送管道

设置 POST
＋ 文件 请求体

再添加“获取 URL 内容”动作。展开设置，把方法改为 POST，请求体选择 文件，文件变量选择“快捷指令输入”。

最后应该是：
方法 = POST
请求体 = 文件
文件 = 快捷指令输入
显示通知 = URL 内容
“快捷指令输入”是什么意思？
它就是以后从 Safari、照片或其他 App 分享进来的网页、文字或图片。
