登录有什么不同？

不登录

内容保存在当前浏览器。适合先试用；换浏览器或清理网站数据后，内容不会自动跟过去。

登录后

内容进入你的云端账号。电脑、手机和其他浏览器登录同一个邮箱，就能看到同一份 Later Space。
