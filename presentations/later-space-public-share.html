本身的优化

不是增加更多功能，而是让最常用的资讯先被看见，让素材在需要的时候再出现。

03 / use case — default view
04 / 12
我只想找刚刚收藏的资讯
先看到链接和文字，
再去找素材。

默认入口不再把图片、视频和资讯全部混在一起。最常用的阅读内容先出现，视觉素材留在 Visual Space。

线上画布 / 默认入口 + Visual Space + 全部
1
链接与文字优先先处理稍后阅读的内容。
2
素材单独放置图片和视频进入 Visual Space。
04 / use case — long text
05 / 12
我复制了一大段文字，但不想看到文字墙
先变成卡片，
再决定什么时候读。

长文字先自动截取临时标题，和链接一样成为一个清楚的信息源。第一期不依赖 AI，也不需要 API key。

一张文字卡片

从复制粘贴开始，Later Space 先帮你把它变成一个可以辨认的入口。

1
截取临时标题不用等待 AI 生成。
2
点击查看全文卡片负责区分，正文负责阅读。

Later Space 插件

收藏不必先离开内容。插件把动作放回网页、文字、图片和视频出现的地方。

06 / use case — whole page
07 / 12
我想收藏整篇文章，稍后再读
点击一次，
网页就被接住。

不用复制网址，也不用先打开 Later Space。插件自动读取当前页面的标题和链接，保存后给出明确反馈。

一篇值得稍后再读的文章

点击浏览器右上角的 Later Space 图标，保存当前页面。

已加入 Later Space
1
点击插件自动读取网页标题与链接。
2
点击查看打开线上画布并定位最新内容。
07 / use case — selected text
08 / 12
我只想留下网页里的某一段话
选中它，
它就变成卡片。

插件不要求你先判断“收藏文字”还是“收藏网页”。你只需要选中内容，完成选区后再点击一次。

真实截图 / 选区完成后出现一个图标
1
选中文字选区完成前不出现按钮。
2
点击浮动图标一段选区只出现一个，尽量不遮挡阅读。
08 / use case — image & video
09 / 12
我只想收藏一张图片或一个视频封面
看到素材，
就地加入。

在小红书、X 或图片搜索里，不必先截图再粘贴。悬停图片或视频封面，或者右键使用统一入口。

图片 / 视频封面

悬停素材，选择 加入 Later Space。

1
图片与视频都能接住视频当前保存封面并保留来源。
2
右键入口统一只需要记住一句：“加入 Later Space”。

收藏不是点击按钮就结束。用户需要看见最近内容、知道它在哪里，也需要在误触时能退回来。

10 / design decisions
11 / 12
每一个细节，都来自一个具体的不顺手

问题变成改动。

收藏之后不知道去哪了
最近收藏 + 查看定位
选区按钮挡住正文
延迟出现 + 只出现一个
右键菜单太复杂
统一叫“加入 Later Space”
误收藏无法回退
增加撤销入口
长文字铺成一面墙
先卡片化，再查看全文
图片入口只适配一个平台
扩展到更多网页场景
