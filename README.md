# Later Space 无限收藏画布

一个本地无限收藏画布。文字、图片、网址与社媒分享文案使用同一个入口，也可以直接粘贴到画布；支持「全部 / 图片 / 链接 / 文字」分类视图。链接会提取标题并生成极简文字海报，可从海报或选中工具栏打开原内容。

## 在线版

在线版采用本地优先架构：每位用户的收藏只保存在自己的浏览器 IndexedDB 中，不会上传到公共仓库，也不会与其他用户混用。更换浏览器或清理网站数据前，请先使用底部下载按钮导出备份；旁边的上传按钮可导入 JSON 备份并迁移完整画布。公开静态版暂不提供自动备份、外部收件箱与多设备云同步。

选中图片后，可以点击「复制图片」或按 `Command/Ctrl + C`，再粘贴到飞书、微信或 Figma。

底部工具栏支持一键整理画布，再次点击即可还原整理前的位置。

文字采用紧凑黑底样式，支持选中后编辑或双击编辑，并可通过右下角手柄等比例缩放整块文字。

## 启动

```bash
cd /Users/mengwangran/later-space-image-inbox
python3 server.py
```

浏览器打开 `http://127.0.0.1:5177`。

## 收件箱与阅读状态

插件、快捷指令和画布内添加的内容会先进入「收件箱」。之后可以将单条或多条内容设为「未读 / 有启发 / 准备行动 / 已读」；顶部工作流按钮可快速切换。页面打开期间每 20 秒检查一次外部收件箱，切回页面时也会立即检查。

## Chrome 插件

1. 打开 `chrome://extensions` 并开启右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择 `extensions/later-space/`。
3. 浏览网页时点插件图标，可选填一句用途后保存。
4. 若服务地址或令牌不同，在插件详情中打开「扩展程序选项」修改。

插件默认连接 `http://127.0.0.1:5177`，因此本地服务需要保持运行。

## iPhone 分享入口

访问 `http://127.0.0.1:5177/mobile/ios-shortcut.html` 查看快捷指令设置。电脑和手机需在同一 Wi-Fi，并这样启动服务：

```bash
LATER_SPACE_HOST=0.0.0.0 LATER_SPACE_CAPTURE_TOKEN="换成一段随机密码" python3 server.py
```

然后把快捷指令接口改成 `http://电脑局域网IP:5177/api/inbox`。默认只监听本机，不会主动暴露给局域网。

## 可选云同步

不配置云服务时，本地收藏、自动备份和导入导出都可正常使用。Supabase 免费额度足够个人早期使用；公开给更多用户后，存储量和流量超过免费额度才需要付费。创建一个私有 Storage bucket 后设置：

```bash
SUPABASE_URL="https://你的项目.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="服务端密钥" \
LATER_SPACE_SUPABASE_BUCKET="later-space" \
python3 server.py
```

`SUPABASE_SERVICE_ROLE_KEY` 只放在运行服务的电脑或服务器环境变量里，不要写进网页、插件或仓库。画布底部的云朵按钮可手动上传和恢复完整备份。

图片与画布位置保存在当前浏览器的 IndexedDB 中。运行本地服务时，内容变化会自动写入 `backups/`，滚动保留最近 10 份状态备份；图片资产按内容哈希只保存一次，避免每次拖动或编辑都重新编码全部高清图片。底部时钟按钮可恢复上一个版本，下载按钮仍可导出完整的独立备份文件。

链接、文字和图片分别按规范化网址、正文和图片内容哈希检测重复；发现重复时会用站内弹窗询问是否仍要收藏，也可以直接定位原内容。图片原图保存在独立的 IndexedDB 资产库；当前版本直接使用原图 Blob 显示，以避开部分 Chrome 环境的 Canvas 黑图问题。内容达到 80 条后，画布只渲染当前视口附近的卡片，搜索输入也会防抖，以降低高清图片和大量 DOM 带来的内存压力。

按住 `Shift` 拖动画布空白区域可以框选多项，`Shift` 点击可以追加或取消单项选择；选中内容后可以按需添加或移除标签，多选时可批量整理。新粘贴的内容不会弹出表单，没有标签时自动出现在「未整理」中；使用过的标签会自动成为顶部快捷筛选入口。标签栏末尾的管理按钮支持重命名、合并、删除和撤销。底部数据库按钮会显示浏览器容量、原图资产、收藏数量和自动备份状态。

运行数据安全验收：

```bash
python3 -m unittest tests/test_backup_recovery.py
```

恢复接口会跳过损坏的 JSON 备份和缺失图片资产的版本，自动寻找最近一份完整备份。

`backups/` 也可以放进 iCloud Drive、Dropbox 或其他同步盘，作为零额外成本的个人备份方式。

例如将自动备份直接写入 iCloud Drive：

```bash
LATER_SPACE_BACKUP_DIR="$HOME/Library/Mobile Documents/com~apple~CloudDocs/Later Space Backups" python3 server.py
```
